홈 화면에서
휴스코프 열기

Safari의 ‘홈 화면에 추가’를 이용하면 휴스코프 아이콘으로 앱처럼 실행할 수 있어요.

아래 그림은 설명용 예시예요. iOS 버전과 Safari 설정에 따라 메뉴 위치가 조금 달라질 수 있어요.

  1. 1

    Safari에서 휴스코프 열기

    아래 버튼을 눌러 휴스코프를 열어주세요. 설치할 주소는 hscope.onrender.com/hscope예요.

    휴스코프 열기 ↗

    카카오톡·ChatGPT 등 앱 안에서 보고 있다면 앱 메뉴의 ‘Safari에서 열기’를 이용하세요. 해당 메뉴가 없으면 아래 주소를 복사해 Safari 주소창에 붙여넣어 주세요.

  2. 2

    공유 → 홈 화면에 추가

    Safari의 공유 버튼(네모 위에 ↑)을 누르고, 메뉴를 아래로 내려 ‘홈 화면에 추가’를 선택하세요.

    공유 버튼이 안 보이면 페이지 메뉴(···)를 누른 다음 ‘공유’를 선택하세요. ‘홈 화면에 추가’가 목록에 없다면 맨 아래 ‘동작 편집’에서 추가할 수 있어요.

  3. 3

    웹 앱으로 열기 → 추가

    이름이 ‘휴스코프’인지 확인하고, ‘웹 앱으로 열기’가 보이면 켜주세요. 오른쪽 위 ‘추가’를 누르면 설치가 완료돼요.

    이전 iOS 버전에서는 ‘웹 앱으로 열기’ 옵션이 없을 수 있어요. 그대로 ‘추가’를 누르면 돼요.

  4. 4

    홈 화면 아이콘으로 실행

    홈 화면에 생긴 파란 조준경 모양의 휴스코프 아이콘을 누르세요. 주소창 없이 모바일 세로형 화면으로 열려요.

    ‘추가’를 누른 기기의 홈 화면에 아이콘이 생성돼요. 아이폰과 아이패드에서는 각각 추가해 주세요.
